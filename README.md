# Города во времени

Интерактивный исторический атлас: MapLibre, React, TypeScript, Sites/Vinext. География и набор населения поставляются вместе с сайтом; платные ключи и серверная база не нужны.

## Разработка

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Статический результат: `dist/client`. Метаданные Sites: `.openai/hosting.json`. Для другого статического хостинга достаточно опубликовать `dist/client` в корне домена. `catalog.json` и GeoJSON должны отдаваться с HTTP-сжатием. Работа из подкаталога потребует настройки базовых путей.

[Данные, обновление и ограничения](DATA.md). Проверки интерфейса и ограничений браузера описаны в `QA.md`.

Пробел — воспроизведение; `/` — поиск; Esc — закрыть. Ссылка хранит год, город, камеру и главу. При недоступном WebGL работают список и карточки.
