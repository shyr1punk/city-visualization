# Города во времени

Интерактивный исторический атлас с мировым импортом Wikidata и фильтрами по континентам и странам: MapLibre, React, TypeScript, Sites/Vinext. География и набор населения поставляются вместе с сайтом; платные ключи и серверная база не нужны.

## Разработка

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Статический результат: `dist/client`. Метаданные Sites: `.openai/hosting.json`. Для другого статического хостинга достаточно опубликовать `dist/client` в корне домена. `catalog.json` и GeoJSON должны отдаваться с HTTP-сжатием. Работа из подкаталога потребует настройки базовых путей.

[Данные, обновление и ограничения](DATA.md). Проверки интерфейса и ограничений браузера описаны в `QA.md`.

Пробел — воспроизведение; `/` — поиск; Esc — закрыть. Ссылка хранит год, город, камеру и главу. При недоступном WebGL работают список и карточки.

## Мировой каталог

`npm run data:refresh-world` сохраняет возобновляемую выгрузку Wikidata в `data/raw/world`. После её завершения `npm run data:import` воспроизводит мировой каталог без сети. Незавершённый снимок импортировать нельзя. Текущее состояние отражено в `public/coverage-summary.json` (`worldComplete`) и в методологии сайта.

`data/legacy-catalog.json` — сохранённый проверенный каталог: его идентификаторы, даты и наблюдения имеют приоритет при объединении по QID. Прежняя цепочка импорта доступна как `data:import-legacy` и предназначена только для отдельного обновления исходной части, после которого следует мировой импорт.

Фильтры допускают несколько территорий. Между континентами и странами действует пересечение; пустой выбор означает все территории. Ссылка сохраняет `continents`, `countries`, `undated` вместе с годом и камерой. На мобильном экране фильтры открываются кнопкой. Города без даты включаются отдельным переключателем и не попадают в исторический счётчик.

Индекс `public/catalog-index.json` загружается первым; история и источники — порциями до 300 городов одной страны из `public/catalog/`. Каталог показывает по 100 записей на странице. `node --experimental-strip-types scripts/benchmark-world.ts` измеряет фильтрацию и подготовку маркеров на текущем и синтетическом нагрузочном наборе.

### Продолжение длительной выгрузки

`npm run data:refresh-world` запускает один координатор `scripts/resume-world.py`: получает полный список QID через WDQS, загружает свойства через официальный `wbgetentities`, затем импортирует завершённый снимок и выполняет тесты. Второй экземпляр не запускается, пока работает первый. Паузы обоих сервисов сохраняются и выдерживаются автоматически. Процесс конечный: завершает работу после готового каталога или непредвиденной ошибки; сайт не публикует.

Текущее состояние — `data/raw/world/download-status.json`, журнал фонового запуска — `data/raw/world/download.log`. Сжатые снимки записей сохраняются в `data/raw/world/entities/`, нормализованные порции импорта — `api-v1-*.json.gz`. Повторная загрузка готовых записей не нужна. Поисковые запросы отправляются не чаще одного раза в 65 секунд; запросы свойств — с интервалом не менее 6,5 секунды и отдельным соблюдением Retry-After.
